laland

A Doom Emacs theme first, then kitty, KDE, GTK and Firefox. Midnight-blue ground, vivid accents tuned for long reading, doom-one's slot layout with pink in the magenta slot.

How the colors were picked

How it was decided

  1. Built the way doom-themes works

    A doom theme fills about ten slots (keywords, functions, strings, type, constants, numbers, builtin, variables, operators, comments). doom-themes derives every Emacs face from them: function calls are functions blended 70% into the text color, punctuation is operators at 25%, properties are keywords at 60%. The colors on this page are computed with the same math.

    doom-themes-base.el:34-60 · doom-themes.el:301-343
  2. doom-one's slot layout

    You picked it in round 4: keywords blue, functions and builtins magenta, strings green, types yellow, constants violet, numbers orange. laland puts its pink in the magenta slot.

    doom-one-theme.el:98-109
  3. Pink drives the highlight slot

    doom-one uses blue there. In laland the cursor, links, minibuffer prompt, current line number and modeline bar all come from highlight, so they're pink.

    doom-themes-base.el:16-29
  4. Midnight-blue ground

    The pink-tinted near-black read brown, and the violet-tinted grey was rejected too. The ground is a navy (OKLCH L 0.255, hue 270): round 1 picked the hue, comfort round 6 lifted it from L 0.17 to the lightest option so text stops glowing.

    rounds 1–2 of the picker
  5. Vivid without the highlighter look

    Pink, blue and violet run at 100% of the saturation a screen can show, after nudging their hues (pink 350→340, blue 255→238) to where they can be bright and saturated at once. Green, yellow and cyan stay at 85%: at 100% their channels hit 00/ff (#fcdf00, #00fb48) and look like highlighter ink.

    round 3 of the picker
  6. Final pass: inclusive dark mode

    Checked against Smashing Magazine's inclusive dark mode article. The ground is not pure black. Text is pulled back from white (L 0.925) to cut halation. Every syntax color clears the article's 4.5:1 contrast in both variants. Diff and error colors were re-checked under simulated color blindness (Viénot/Brettel). The rule that fixed the confusions: pairs that carry meaning differ in brightness, not only hue. Constants became a light lavender, strings a darker mint than types, and red sits darker than green.

    smashingmagazine.com 2025/04 · scripts/audit.py · DaltonLens matrices

The palette

Both variants, each on its own background. "Lc" is the APCA contrast of that color as text on the variant's background (higher = more readable; 60 is the floor for code).

;;; laland.el --- pink everywhere  -*- lexical-binding: t; -*-

(defun laland-apca (txt bg)
  "Return the APCA contrast of TXT on BG."
  (let ((y (laland--luminance txt)))
    (when (< y 0.022)
      (setq y (+ y (expt (- 0.022 y) 1.414))))
    (* 100 (- (expt bg 0.56) (expt y 0.57)))))

oklch.pypython
from dataclasses import dataclass
import math

@dataclass(frozen=True)
class Oklch:
    """A color in OKLCH space."""
    L: float
    C: float
    H: float = 350.0

    def to_lab(self) -> tuple[float, float, float]:
        h = math.radians(self.H)
        return self.L, self.C * math.cos(h), self.C * math.sin(h)

theme.rsrust
use std::collections::HashMap;

/// Every role resolves to one RGB value.
#[derive(Debug, Clone)]
pub struct Theme<'a> {
    name: &'a str,
    roles: HashMap<&'static str, u32>,
}

impl<'a> Theme<'a> {
    pub fn get(&self, role: &str) -> Option<u32> {
        self.roles.get(role).copied()
    }
}

fn main() {
    let t = Theme { name: "laland", roles: HashMap::new() };
    match t.get("keyword") {
        Some(c) => println!("{:#08x}", c),
        None => eprintln!("missing role in {}", t.name),
    }
}

import { useState } from "react";

type Variant = "dark" | "light";

export function Toggle({ initial = "dark" }: { initial?: Variant }) {
  const [v, setV] = useState<Variant>(initial);
  const flip = () => setV(v === "dark" ? "light" : "dark");
  return (
    <button className="toggle" onClick={flip} disabled={false}>
      variant: {v}
    </button>
  );
}

Dracula#282a36
def contrast(txt: str, bg: str = "#130f11") -> float:
    """APCA Lc of txt on bg."""
    # soft-clamp near black
    t, b = luminance(txt), luminance(bg)
    if abs(b - t) < 0.0005:
        return 0.0
    return (b ** 0.56 - t ** 0.57) * 114  # \u2192 Lc
